# Пора: Дом

[English version](./README_EN.md)

Android-приложение для повторяющегося ухода за домом. Визуальный кандидат для следующего обновления — `1.0.1` (`ru.poradom.app`, versionCode 16). Отправленная в RuStore версия — `1.0.0` (versionCode 15).

## Что работает

- первоначальная настройка квартиры или дома;
- готовые процедуры и чек-листы;
- стандартные комнаты, их добавление и переименование;
- автоматический перенос связанных дел при переименовании помещения;
- каталог домашних устройств: фильтры воды, роботы-пылесосы, очистители воздуха, кондиционеры, стиральные и кофемашины, датчики;
- выбор марки, помещения и даты установки устройства;
- автоматическое создание рекомендуемых процедур обслуживания с возможностью изменить срок;
- собственные задачи;
- статусы «просрочено / сегодня / скоро»;
- действия «готово» и «отложить»;
- автоматический пересчёт следующего срока;
- локальная история и резервная копия;
- установка как PWA и офлайн-режим.
- три цветовые темы: «Свежий», «Нежный» и «Мастерская»;
- нативные Android-уведомления, работающие при закрытом приложении;
- восстановление расписания после перезагрузки телефона и обновления приложения;
- настройка времени напоминаний;
- приватный переход к поиску нужного магазина рядом;
- серверный каталог CPA-предложений по типу устройства и марке;
- обезличенный `click_id` для учёта каждого перехода в CPA-сеть;
- рекламные ссылки не передают партнёру имя, домашние дела или адрес пользователя;
- нативная Android-оболочка на Capacitor;
- нижний адаптивный баннер с медиацией Yandex, VK Ads, Mintegral и Unity Ads;
- независимый резервный блок прямого спонсора с учётом показов и кликов;
- политика конфиденциальности внутри приложения и отдельная HTML-страница для публикации.

Первый магазинный релиз работает локально, без регистрации и сервера. Вкладка «Семья» автоматически скрыта. Backend семейной синхронизации остаётся в репозитории для следующего этапа и включается только при сборке с production API.

## Устройства — первый этап

Во вкладке «Дом» можно добавить устройство из каталога. Приложение предложит ориентировочные процедуры обслуживания и рассчитает первый срок от даты установки. Каждое созданное дело остаётся обычным редактируемым делом: интервал нужно сверить с инструкцией конкретной модели. Прямого подключения к умному дому на этом этапе нет.

## Локальный запуск

```powershell
node backend/server.mjs
```

Откройте `http://127.0.0.1:4173` в браузере. На Android в Chrome выберите «Добавить на главный экран» или «Установить приложение».

## Семейный тестовый режим для разработки

Во вкладке «Семья» пользователь явно создаёт общий дом либо подключается по коду. После подключения общими становятся комнаты, задачи, ответственные и журнал выполнений; тема, время уведомлений и журнал показанных уведомлений остаются настройками конкретного телефона. При конфликте версий приложение не перезаписывает данные молча, а предлагает выбрать семейную или локальную версию.

Сессия тестового backend анонимная и хранится на устройстве. Функция не включена в 1.0.0: перед публичным запуском синхронизации нужны HTTPS, резервное копирование базы, авторизация с восстановлением доступа и ограничение попыток ввода приглашений.

Требования к нативным Android-разрешениям и планировщику описаны в [`docs/ANDROID_RELEASE.md`](docs/ANDROID_RELEASE.md).
Подключение CPA-предложений и этапы интеграции РСЯ описаны в [`docs/MONETIZATION.md`](docs/MONETIZATION.md).

## Android-сборки

```powershell
pnpm run android:debug
```

Debug APK создаётся в `android/app/build/outputs/apk/debug/app-debug.apk` и использует demo-блок РСЯ.

Подписанный release без рекламы и семейной синхронизации:

```powershell
pnpm run android:release
```

Release с production-баннером и email поддержки:

```powershell
.\scripts\build-release.ps1 -SupportEmail "support@example.ru" -YandexAdUnitId "R-M-0000000-1" -MonetizationApiOrigin "https://api.poradom.ru"
```

Готовые проверенные артефакты находятся в `artifacts/`. Перед загрузкой в магазин нужны email владельца, опубликованная политика, production ID включённых рекламных сетей и HTTPS-адрес monetization API либо осознанный выпуск с отключёнными источниками.
