# Android release 1.0.0

## Параметры

- Application ID: `ru.poradom.app`
- Version: `1.0.0` / versionCode `15`
- minSdk: `24`
- targetSdk / compileSdk: `36`
- Подписанный APK: `artifacts/Pora-Dom-1.0.0-v15-release.apk`
- Подписанный AAB: `artifacts/Pora-Dom-1.0.0-v15-release.aab`

## Поведение первого релиза

Первый магазинный релиз локальный: комнаты, устройства, задачи, сроки и история хранятся на телефоне. Регистрация не требуется. Семейная вкладка скрыта, пока не задан production API. В APK v15 встроен ID нижнего баннера РСЯ `R-M-20425431-1`. До публикации приложения и активации площадки в РСЯ этот блок работает в тестовом режиме. Demo-ID используется только в debug.

Приложение не запрашивает геолокацию. «Найти магазины рядом» открывает внешний картографический поиск только после действия пользователя.

## Напоминания

Реализованы через AndroidX WorkManager `2.12.0`:

- `POST_NOTIFICATIONS` запрашивается при первом запуске, повторное управление доступно в настройках;
- пользователь может выключить напоминания внутри приложения;
- ежедневная проверка запускается примерно в выбранное время без exact alarm;
- изменения задач и времени пересоздают расписание;
- тестовое уведомление проверяет системный канал;
- нажатие на уведомление открывает общий список актуальных дел «Сегодня»;
- `ReminderBootReceiver` восстанавливает расписание после загрузки Android и обновления пакета.

На Android 16 доставка `BOOT_COMPLETED` может быть отложена системой в общей очереди загрузки. Проверка на эмуляторе подтвердила, что расписание появляется без ручного запуска приложения после доставки события.

## Разрешения фактического release APK

Приложение объявляет `INTERNET`, `POST_NOTIFICATIONS` и `RECEIVE_BOOT_COMPLETED`. WorkManager и рекламные SDK добавляют сетевое состояние, wake lock, foreground service, advertising ID и служебные разрешения. Геолокации, контактов, телефона, SMS, файлового хранилища и exact alarm нет; чувствительные разрешения принудительно удаляются при слиянии манифестов.

## Реклама

Адаптивное нижнее место использует Yandex Mobile Ads SDK `8.6.0` как слой медиации с адаптерами VK Ads, Mintegral и Unity Ads. В debug используется `demo-banner-yandex`. В release ID передаётся при сборке; при его отсутствии блок скрыт. При отсутствии сетевой рекламы может использоваться размеченная карточка прямого спонсора с отдельного monetization API. Production-настройки передаются только при финальной сборке:

```powershell
.\scripts\build-release.ps1 -SupportEmail "quickbizauto@yandex.com" -YandexAdUnitId "R-M-20425431-1"
```

Перед заполнением анкеты магазина нужно сверить фактическую версию SDK и её обработку данных.

## Подпись

Постоянный RSA-4096 ключ хранится локально:

- `android/signing/pora-dom-release.jks`
- `.release-secrets/keystore-recovery.txt`

Оба пути исключены из Git. Файлы необходимо скопировать минимум в два независимых защищённых места. Потеря ключа не позволит выпускать обновления с тем же package ID.

## Сборка

```powershell
pnpm test
pnpm run android:release
```

Скрипт генерирует нативные иконки и splash из `assets/icon-512.png`, собирает production web bundle, синхронизирует Capacitor, затем создаёт APK и AAB.

## Проверено 15 ноября 2026 года

Для APK v15 проверены успешная подписанная сборка, package/version, вшитый ID РСЯ, подпись APK v2 и совпадение списка разрешений с v14. Следующие функциональные проверки выполнены для v14; единственное изменение v15 — рекламный ID и versionCode:

- полный web E2E и backend API тесты;
- отдельный тест локального production bundle без семейной вкладки;
- Android release build и Lint;
- APK signature v2 и AAB JAR signature;
- package/version и фактические разрешения;
- release-runtime содержит адаптеры VK Ads, Mintegral и Unity Ads;
- тест прямого спонсорского блока, учёта показа и атрибуции клика;
- чистая установка и onboarding;
- фирменные launcher/splash assets;
- системный запрос разрешения;
- WorkManager job, тестовое уведомление и переход к общему списку «Сегодня»;
- восстановление job после обновления и перезагрузки.
- обновление v13 → v14 с сохранением комнат и задач и заменой закэшированных веб-ресурсов.

Карточка и финальный чек-лист находятся в `store/`.
