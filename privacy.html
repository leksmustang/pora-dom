Политика конфиденциальности приложения «Пора: Дом»

Редакция от 15 ноября 2026 года

1. Данные домашнего плана

Комнаты, устройства, задачи, сроки и история выполнений сохраняются локально на устройстве пользователя до удаления данных или приложения. В первом релизе приложение не передаёт домашний план на сервер разработчика.

2. Резервная копия

Файл резервной копии создаётся только по команде пользователя. Пользователь самостоятельно выбирает место хранения и получателей файла.

3. Напоминания

Приложение передаёт локальный список сроков системному механизму Android, чтобы показывать уведомления в фоне. Эти сведения не покидают устройство.

4. Реклама

В приложение встроены рекламные SDK Яндекса и партнёров по медиации. Они могут обрабатывать идентификаторы устройства и SDK, приблизительный регион по сетевым данным, взаимодействия с рекламой, сведения для диагностики и отчёты о сбоях. Эти данные могут передаваться поставщикам SDK для рекламы, измерения и защиты от злоупотреблений. В первом релизе рекламный блок выключен до подключения рабочего рекламного идентификатора. Комнаты, список домашних дел, заметки и адрес пользователя рекламным партнёрам не передаются. Сроки хранения технических данных у поставщиков SDK определяются их правилами; по вопросам обработки данных можно обратиться к разработчику по адресу ниже.

5. Внешние карты и магазины

Поиск магазина запускается только после действия пользователя и открывается во внешнем картографическом сервисе. Поисковый запрос может содержать часть названия выбранного домашнего дела, которую пользователь ввёл в приложении. Внешний сервис получает этот запрос при открытии ссылки. Приложение не запрашивает системное разрешение на геолокацию и не хранит координаты пользователя.

6. Удаление данных

Все данные можно удалить в настройках приложения либо через системную функцию очистки данных Android. Удаление приложения также удаляет локальный домашний план.
